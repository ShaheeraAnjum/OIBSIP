# EDA on Retail Sales Data

This project was completed as part of the Oasis Infobyte Data Analytics Internship.

## Task

Level 1 - Task 1: Exploratory Data Analysis on Retail Sales Data

## Objective

To analyze retail sales data and identify sales trends, customer demographics, product category performance, relationships between numerical variables, and actionable business insights.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset structure and data quality analysis
- Missing value and duplicate checking
- Descriptive statistics
- Monthly sales analysis
- Quarterly sales analysis
- Customer age-group analysis
- Gender analysis
- Product category analysis
- Correlation analysis
- Additional visualization
- Business recommendations

## Dataset Limitation

The dataset contains product categories but does not contain individual product names. Therefore, a true Top 10 Best-Selling Products analysis cannot be performed without introducing information that is not present in the dataset.

## Project Files

- `Retail_Sales_EDA.ipynb` — Complete analysis notebook
- `retail_sales_dataset.csv` — Dataset used for the analysis
- `README.md` — Project documentation
